# LabReport_Heidelberg_tex
This repository provides a LaTeX template for general lab reports. 

## How to git clone this repository to local
```bash
cd your_directory
git clone https://github.com/Akane-ogawa/LabReport_Heidelberg_tex.git

```

## How to compile the PDF 
```bash
xelatex LabReport_name.tex
bibtex LabReport_name
xelatex LabReport_name.tex
xelatex LabReport_name.tex
```
